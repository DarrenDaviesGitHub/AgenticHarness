# Vertical slice checklist

Replace `Product`/`Products` with the new feature name. "Copy" means read the file and follow its structure, naming, XML docs and test style exactly.

## Domain (`src/*.Domain/<Feature>/`)
- [ ] Entity: copy `Products/Product.cs` (sealed, private setters, `field` guards, `Create`/`Update`, constants for limits, private EF constructor).
- [ ] Tests: copy `tests/*.Domain.UnitTests/Products/ProductTests.cs` and `ProductFactory.cs`. One test per invariant.

## Application (`src/*.Application/<Feature>/`)
- [ ] Repository interface in `Common/Interfaces/I<Feature>Repository.cs`: copy `IProductRepository.cs`, only the methods you need.
- [ ] Response record `<Feature>Response.cs` with a static `From<Entity>` mapper: copy `Products/ProductResponse.cs`.
- [ ] Per use case folder `<Verb><Noun>/`:
  - [ ] Command/query record: copy `CreateProduct/CreateProductCommand.cs` or `GetProductById/GetProductByIdQuery.cs`.
  - [ ] Handler: copy `CreateProduct/CreateProductCommandHandler.cs` (writes) or `GetProductById/GetProductByIdQueryHandler.cs` (reads).
  - [ ] Validator (required for every command): copy `CreateProduct/CreateProductCommandValidator.cs`.
- [ ] Tests mirroring the folders: copy `tests/*.Application.UnitTests/Products/**` (one class per handler and per validator, `TestData` helpers).

## Infrastructure (`src/*.Infrastructure/`)
- [ ] `DbSet` in `Persistence/ApplicationDbContext.cs`.
- [ ] Configuration: copy `Persistence/Configurations/ProductConfiguration.cs` (max lengths from constants, unique indexes, decimal precision).
- [ ] Repository: copy `Persistence/Repositories/ProductRepository.cs` (`AsNoTracking` for reads, deterministic ordering for paging).
- [ ] Register in `DependencyInjection.cs` (`AddScoped<I<Feature>Repository, <Feature>Repository>()`).
- [ ] Migration: `/add-migration Add<Feature>` (never hand-edit the generated files).

## Api (`src/*.Api/`)
- [ ] Request records in `Contracts/`: copy `CreateProductRequest.cs` / `UpdateProductRequest.cs` with `ToCommand(...)`.
- [ ] Controller: copy `Controllers/ProductsController.cs` (thin actions, `Async` suffix, XML docs, one `ProducesResponseType<T>` per status, `CreatedAtAction` for POST, `NoContent` for PUT/DELETE).
- [ ] New exception type? Map it in `ExceptionHandling/GlobalExceptionHandler.cs` and add an ADR.
- [ ] Append requests to `*.Api.http`.

## Integration tests (`tests/*.Api.IntegrationTests/<Feature>/`)
- [ ] Copy `Products/ProductsEndpointsTests.cs`: one test per contract row, `ShouldBeProblemAsync<T>` for errors, unique keys per test.

## Docs
- [ ] HTTP contract table in `CLAUDE.md`.
- [ ] `docs/openapi.json` regenerated by the build and staged.
